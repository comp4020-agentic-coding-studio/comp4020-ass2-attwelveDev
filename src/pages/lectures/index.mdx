# Lectures

<p class="lead">What is covered, week by week, and which topics each lecture draws on.</p>

Every lecture the course claims to run gets a dated page and a teaching-team
reference. A course decides how many lectures it needs; one of them carries a
real deck. Each lecture links out to the sessions and assessments that draw
on it. Every citation a lecture draws on is collected on the
[references page](/references/).
