## Introduction

Would what you're wearing right now survive summer, winter, or just
today's actual forecast? Clothing measurably changes how a wearer thinks
and acts, not just how they're perceived — today's scope is
occasion-matching and basic colour coordination only, the one topic in
the course with genuinely surprising research behind it.

## Body

- **Clothing changes cognition, not just perception.** Adam, H., &
  Galinsky, A. D. (2012) found a coat described as a doctor's lab coat
  measurably improved sustained attention versus the same coat described
  as a painter's coat — the effect needs both the physical experience of
  wearing it and its symbolic meaning.

<CheckIn question="Name the two factors enclothed cognition depends on." />

- **Reading an occasion, in two checks.** Run the occasion check first:
  what formality does the event itself require — a lecture reads casual,
  a gym session reads athletic (exercise itself is Week 4's topic), an
  interview (Week 11) reads formal. Then run the weather check: does
  today's weather and season break that outfit, not the event. A linen
  shirt and light jacket read as correctly casual for a lecture on a mild
  day; the same outfit is still wrong in a summer heatwave — soaked
  through before you arrive — or a winter cold snap with nothing that
  blocks wind, no matter how well it matched the event on paper — an
  outfit that passes the occasion check and fails the weather check is
  still the wrong outfit.

<CheckIn question="What's the one detail that would flip an outfit from interview-appropriate to gym-appropriate?" />

- **Assembling from what you own.** List your own recurring occasion types
  once — lectures, gym, one social event a week, say — and settle on one
  reliable outfit per type instead of deciding from scratch each time. A
  wardrobe only has to cover a small number of recurring occasion types,
  not one item per occasion — Assignment 1 previews the same task.

<CheckIn question="How many genuinely different occasion types does your own week actually contain?" />

## Conclusion

What you wear changes how you perform, not just how you're seen — the
closest thing in this course to a genuine hack. You can now run both
checks — occasion first, then weather — and assemble an outfit from a
wardrobe that only has to cover a handful of recurring types. Coming up:
this week's lab (the outfit ranking exercise).
